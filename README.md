# 📦 Resource Management System

A **Resource Management System** designed to simplify and automate the management of resources using **Microsoft SharePoint, Power Automate, and Excel**.

The system helps organizations maintain resource records, monitor availability, identify shortages, and automate notifications and updates, reducing manual tracking and improving resource management efficiency.

---

## 📌 Project Overview

Managing resources manually can lead to data duplication, delayed updates, resource shortages, and difficulty in tracking availability.

The **Resource Management System** provides a centralized solution where resource information can be stored and managed efficiently. **SharePoint** is used for centralized data storage, **Power Automate** is used to automate workflows and notifications, and **Excel** is used for data analysis and reporting.

---

## 🔧 System Workflow

1. Resource information is entered into the system.
2. The information is stored in a **SharePoint list**.
3. **Power Automate** monitors the resource information.
4. The workflow checks resource availability and requirements.
5. If a shortage is identified, an automated alert/notification is triggered.
6. Resource information can be analyzed through **Excel**.
7. Teams can use the updated information to make better resource allocation decisions.
